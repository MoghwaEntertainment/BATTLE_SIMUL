## 2. `BattleSimulation.Step()` 1 tick 실행 순서

![Step 실행 순서](diagrams/02_Step_실행순서.png)

| 순서 | 함수 | 역할 | 호출하는 함수 |
| --- | --- | --- | --- |
| 1 | `UpdateTimers()`, `ConfirmDeaths()` | 버프 만료(능력치 재계산), 상태이상 게이지 감소, 중독 피해, 빙결·기절·경직 해제, 강인도·스태미나 회복, 사망 확정 | `ExpireBuffs()` → `RecalcStats()` |
| 2 | `UpdateTargets()`, `CollectDecisions()` | 3 tick 마다 타겟 갱신과 AI 의도 수집 | `UpdatePhase()`, `Decide()` → `BuildPlan()` (`AiCondition.Evaluate`, `ResourceRules.Check`, `ResolveMoveset`) |
| 3 | `ApplyDecisions()` → `StartAction()` | 자원 재검사, 비용 차감, 행동 시작, 쿨다운·콤보 기록, 시전 시(ON_CAST) 버프 | `EndAction()` (캔슬 연결 시), `TriggerBuff()` |
| 4 | `AdvanceActions()` | 행동 진행 시간 누적(ElapsedMs 감속 / RealElapsedMs 고정), 이동·추적, 타격 시점 도달 수집 | `MoveSoft()`, `AdvanceSkill()` |
| 5 | `ResolveOverlaps()` | 개체 겹침 해소, 전장 경계 | — |
| 6 | `ResolveHits()` → `ApplyHit()` | 같은 tick 타격 동시 해결: 무적, 가드, 피해, 기절 누적·저항 판정(ApplyBuildup), 강인도(경직 중이면 강인도 무적 — HP 만 감소, `poiseImmuneWhileStaggered`). 경직·가드 브레이크·기절·중독·빙결 발동은 예약만 하고(`QueueState`) 모든 타격 해결 후 `FlushPendingStates()` 로 일괄 적용 — 같은 tick 의 다른 타격은 tick 시작 상태(가드 유지·그로기 아님)로 계산. 이어서 적중 시(ON_HIT) 버프 적용 | `GatherTargets()`, `DamageFormula.Compute()`, `ApplyBuildup()`, `QueueState()`, `FlushPendingStates()` → `ApplyState()` → `QueueInterrupt()`, `FlushPendingBuffs()` → `TriggerBuff()` |
| 7 | `ApplyInterrupts()`, `FinishActions()` | 경직·기절 행동 강제 중단과 콤보 초기화(사유는 기절 > 경직 우선), 끝난 행동 종료, 끝까지 수행한 행동의 완료 시(ON_END) 버프 | `EndAction()`, `TriggerBuff()` |
| 8 | `ConfirmDeaths()`, `CheckEnd()` | 사망 확정, 승패·동시 전멸·시간 초과 판정 | `EndBattle()` → `BattleResult` |

각 단계에서 생긴 사건은 `NewEvent()` → `Emit()` 으로 구독자에게 전달된다. 구독자는 기록만 하며 전투 결과를 바꾸지 않는다.

## 3. Unity 프레임 루프(관찰 모드)

```
SimulationBootstrap.Update()
  ├─ VisualSimulationRunner.Update(unscaledDeltaTime)  → BattleSimulation.Step() × N
  │    판 종료 시 OnObserveFinished() → (자동 다음 회차) UpdateAutoNext() → PrepareObserve(next, keepCamera:true)
  ├─ HandlePointer()   마우스 선택, 단축키(Space, ., F, Ctrl +/- 글자 배율 요청)
  └─ UpdateViews()     CombatantView.Apply()(DisplayElapsed → 몸 기울임·구르기·무기) / ResourceBarsView.Apply()
                      / UpdateAttackFx() → AttackFx.Advance(Tick-2+alpha) (종료 후 AdvanceBy) / DebugDraw
  (Step 중 발생한 이벤트 → ViewEventSink.OnEvent() → LookOf()(SkillId → AttackLooks.For) → AttackFx.Spawn(kind, look, …), 꺼져 있으면 즉시 점멸)
SimulationBootstrap.OnGUI()
  ├─ EnsureStyles()    전용 GUISkin, 배율 요청을 Layout 단계에서 반영 → ApplyUiScaleToStyles()
  ├─ DrawEntityLabels() 머리 위 이름(줄바꿈 없음, 글자 크기에 맞춘 칸, 1px 그림자) → DrawStatusTags() 이름 위 상태 글자
  └─ DrawTopBar() / DrawLeftPanel() / DrawRightPanel() / DrawLogPanel()(오래된 줄 위·최신 아래, 맨 아래 따라가기) / DrawPicker()(전체 목록, 보이는 줄만 그리는 가상 스크롤)
CameraRig.LateUpdate()  카메라 회전·확대·이동
```
